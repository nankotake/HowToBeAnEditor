## Demo（H5 可玩原型）

`demo/` 目录是一个零依赖的原生 H5 原型（HTML + CSS + JS，无需构建），界面采用 DaVinci Resolve 风格的深色专业主题，重点验证剪辑页面的手感与布局。

### 运行方式

```bash
# 任意静态服务器即可，例如：
python -m http.server 8765 --directory demo
# 然后浏览器打开 http://127.0.0.1:8765/index.html
```

### 已实现

- Resolve 风格四区布局：素材库 / 预览 / 检查器 / 时间线
- 素材剪切、自由拖动摆放（可留空隙，重叠自动弹回）、分割、删除、边缘裁剪
- 节奏点系统：好点/坏点吸附 + 特效反馈（Perfect Cut / 剪坏啦）
- 异常点：永不吸附，正好停上会触发 "？" 反馈（监控录像、灵异素材）
- 构图：画面拖动 + 居中/三分线吸附、缩放滑条
- 调色：原片/日系/喜庆/冷调/恐怖 预设
- 播放/走带、需求单浮层、交付评分与客户反馈、接下一单

### 未实现（后续迭代）

- 撤销/重做、存档、工作室经营
